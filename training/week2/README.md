# Week 2: Analog, digital and serial communication

> 🚧 **Under construction.** The assignment and starter code aren't ready yet.

Planned topics:
- **Digital vs. analog signals**: logic levels, pull-ups/pull-downs, ADC resolution and reference voltage.
- **Taproot GPIO wrappers**: `tap::gpio::Digital` / `tap::gpio::Analog` and how they map to the pins in `board.hpp` (the wrappers you skipped in week 1).
- **Serial communication**: what UART is (baud rate, start/stop bits, TX/RX crossover), and how it compares to CAN, SPI and I²C on the robot.
- **Parsing a UART message**: framing, header/magic bytes, packed structs, lengths and checksums, and handling partial or garbage data.
